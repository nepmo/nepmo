### About Me:
I am a Master’s student in Physics at LMU Munich, specializing in data science, observational cosmology, and meteorology.

### Current Projects:
Here are selected scripts from projects I am working on:

**[ZUNN](https://github.com/nepmo/zunn_publ) Z-Uncertainty Neural Network**

Trains a neural network to predict redshift uncertainty from galaxy spectra.

**[target_selection](https://github.com/nepmo/target_selection_publ) 4C3R2 Target Selection**

Creates the 4C3R2 target catalog and visulizes different iterations.

**[fimoni](https://github.com/nepmo/fimoni_publ) File Monitoring**

A file monitoring framework developed for Max Planck Information and Technology, MPDL. It supervises changes to directories, files, sheets, and columns, and reports them to Slack or Mattermost.

**[submitinf](https://github.com/nepmo/submitinf_publ) Submitting Author Inference**

A PostgreSQL framework for inferring the submitting author and APC-paying institution for scientific publications from Web of Science records, validated against DEAL ground-truth data. Developed for Max Planck Information and  Technology, MPDL.
